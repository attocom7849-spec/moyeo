# 모여

모임 참여자의 출발지와 시간 조건을 모아 공평한 만남 장소를 제안하는 반응형 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열거나 이 폴더에서 정적 웹 서버를 실행하세요.

## 주요 흐름

- 모임 생성 및 초대 링크 공유
- 출발지, 도착지, 가능 시간 입력
- 추천 만남 장소 3곳 비교 및 선택
- 주변 장소 카테고리 필터링
- 카카오톡 공유 SDK 연결부

추천 경로와 주변 장소 데이터는 데모용입니다. 모임과 참여자 조건은 Upstash Redis에 공유 저장하고 모임 화면에서 2.5초마다 새 변경 사항을 확인합니다. 저장된 모임은 마지막 수정 후 90일이 지나면 자동 삭제됩니다.

## 공유 저장소 연결

Vercel Marketplace에서 Upstash Redis 저장소를 프로젝트에 연결하세요. Vercel Function은 `UPSTASH_REDIS_REST_URL`과 `UPSTASH_REDIS_REST_TOKEN` 환경 변수를 서버에서 읽습니다. 브라우저에 토큰을 노출하지 않습니다.

## 카카오톡 공유

카카오 JavaScript 키와 공개 HTTPS 도메인을 설정해야 공식 카카오톡 공유창을 사용할 수 있습니다. [KAKAO_SETUP.md](./KAKAO_SETUP.md)와 `config.js`를 참고하세요.
